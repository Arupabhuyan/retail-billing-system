# Retail Billing System

A Retail Billing System developed using **Python and MySQL** for managing products, generating customer bills, and storing billing information efficiently.

## Features

* Add new products
* View available products
* Update product details
* Delete products
* Generate customer bills
* Calculate total bill amount
* Store product and billing data using MySQL

## Technologies Used

* Python
* MySQL
* MySQL Workbench

## Project Purpose

This project was created to practice Python programming and database management using MySQL. It helps demonstrate how Python can interact with a database to manage retail store products and generate customer bills.

## How to Run the Project

1. Install Python on your system.
2. Install MySQL and MySQL Workbench.
3. Create the required database using the SQL file provided in this repository.
4. Update the MySQL database connection details in the Python code.
5. Run the Python file.
